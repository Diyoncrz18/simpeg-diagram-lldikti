Dasar Penyusunan Flowchart

Flowchart dibuat berdasarkan modul Fase 1 yang sudah tersusun dalam PRD v1.1, user story, dan issues: autentikasi SSO, data pegawai, import CSV, cuti, EWS, notifikasi, audit log, dashboard, laporan, dan konfigurasi referensi.

Tech Stack Laravel 12, Blade, PostgreSQL 17, container untuk development.
SSO Keycloak sebagai autentikasi, RBAC tetap dikelola internal aplikasi.
Cuti Tahap awal memakai alur seragam lewat Kabag/verifikator lalu pimpinan.
EWS BUP dihitung dari maksimal usia pensiun pada referensi jabatan.
