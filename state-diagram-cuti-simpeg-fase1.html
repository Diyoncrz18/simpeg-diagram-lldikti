State Diagram Cuti

Perubahan status pengajuan cuti Fase 1 dengan approval chain tiga tahap dan dukungan skip approver duplikat.

Status Pengajuan Cuti

Status mengikuti alur Atasan Langsung -> Kabag/Verifikator -> Pimpinan/PYBMC. Jika approver pada stage berikutnya sama dengan approver sebelumnya, engine boleh melakukan skip sesuai konfigurasi.

stateDiagram-v2
    [*] --> Draft
    Draft --> Validasi: submit pengajuan
    Validasi --> Draft: data belum lengkap
    Validasi --> MenungguAtasan: saldo, jenis cuti, hari kerja valid
    Validasi --> GagalValidasi: tidak punya atasan / saldo tidak cukup
    GagalValidasi --> Draft: perbaiki data

    MenungguAtasan --> DitundaAtasan: tunda + alasan
    DitundaAtasan --> Draft: pegawai revisi / ajukan ulang
    MenungguAtasan --> TentukanStage2: disetujui stage 1

    TentukanStage2 --> MenungguKabag: approver stage 2 berbeda
    TentukanStage2 --> TentukanStage3: skip stage 2 karena approver sama

    MenungguKabag --> DitundaKabag: tunda + alasan
    DitundaKabag --> Draft: pegawai revisi / ajukan ulang
    MenungguKabag --> TentukanStage3: disetujui stage 2

    TentukanStage3 --> MenungguPimpinan: approver final berbeda
    TentukanStage3 --> Disetujui: skip final jika konfigurasi mengizinkan

    MenungguPimpinan --> DitundaPimpinan: tunda + alasan
    MenungguPimpinan --> Ditolak: tidak disetujui
    MenungguPimpinan --> Disetujui: keputusan final setuju

    Disetujui --> SaldoDikurangi: jenis cuti mengurangi saldo
    Disetujui --> Selesai: jenis cuti tidak mengurangi saldo
    SaldoDikurangi --> Selesai
    Ditolak --> Selesai
    Selesai --> [*]

    note right of MenungguAtasan
      Stage 1: Atasan Langsung
      aksi: mengetahui atau tunda
    end note

    note right of MenungguKabag
      Stage 2: Kabag/Verifikator
      aksi: menyetujui atau tunda
    end note

    note right of MenungguPimpinan
      Stage 3: Pimpinan/PYBMC
      aksi: keputusan final
    end note
Setiap transisi approval, tunda, tolak, dan finalisasi wajib dicatat di audit log dan memicu notifikasi ke pihak terkait.
