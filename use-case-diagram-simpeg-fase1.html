Use Case Diagram Fase 1

Artefak ini disusun dari PRD, User Stories, Issues, rekap kebutuhan, diagram v0.4, dan hasil meeting teknis terbaru. Fokusnya adalah scope Fase 1: autentikasi, data pegawai, import Excel/CSV, cuti, EWS, notifikasi, audit, dashboard, laporan, dan konfigurasi referensi.

Analisis Sumber Dokumen

Diagram ini dibuat setelah membaca seluruh file Markdown di folder LLDIKTI dan sudah disinkronkan dengan PRD v1.1 sebagai acuan utama Fase 1/Core.

PRD v1.1 Sumber utama modul, role, data model, API, NFR, dan batasan Fase 1.
User Stories Sumber detail use case per epic dan acceptance criteria.
Issues Validasi breakdown pekerjaan teknis per sprint dan prioritas implementasi.
Hasil Meeting Koreksi desain: SSO via Keycloak, RBAC internal, approval cuti awal lewat Kabag/verifikator, skip approver duplikat, BUP berbasis jabatan.

Keputusan teknis terbaru: Laravel 12, Blade, PostgreSQL 17, container untuk development, Podman diprioritaskan untuk production, dan email testing memakai Mailpit.

Aktor Sistem

Pegawai Mengakses profil, cuti pribadi, saldo cuti, notifikasi, dan EWS pribadi.
Kepala Bagian Melihat bawahan dan dapat menjadi approver pada alur dinamis.
Kabag / Verifikator Menjadi verifikator approval cuti pada alur awal.
Pimpinan Approval final, dashboard pimpinan, data read-only, dan laporan.
Admin Kepegawaian Mengelola data pegawai, import, cuti, EWS, audit, dashboard, dan laporan.
Super Admin Mengelola konfigurasi, reference table, role, permission, dan akses penuh.
Keycloak SSO Sistem eksternal untuk autentikasi login.
Scheduler Sistem Menjalankan EWS harian dan kalkulasi otomatis.
Email Service / Mailpit Mengirim email production atau menguji email saat development.

Catatan Scope Fase 1

Use case utama Fase 1 meliputi:

Auth SSO RBAC Internal Data Pegawai Import Excel/CSV Cuti EWS Notifikasi Audit Log Dashboard Laporan Reference Table

Fitur seperti klaim kehadiran, surat tugas, kalender virtual, log harian, SKP, tracker 20 JP, IP-ASN, dan integrasi SIASN/BKN dicatat sebagai fase lanjutan.

Use Case Diagram SIMPEG Fase 1 - dibuat untuk evaluasi desain sebelum development lanjutan.
