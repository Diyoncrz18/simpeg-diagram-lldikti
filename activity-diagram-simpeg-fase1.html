SIMPEG LLDIKTI Wilayah XVI

Activity Diagram Fase 1

Aktivitas utama Fase 1 dari login SSO, pengelolaan data pegawai, import Excel, pengajuan cuti, EWS, sampai laporan dan audit.

Acuan Requirement

Diagram ini mengikuti PRD Fase 1/Core: Keycloak hanya untuk SSO, role dan permission dikelola internal SIMPEG, import awal mengikuti `daftar_pegawai.xlsx`, approval cuti berjalan melalui Atasan Langsung, Kabag/Verifikator, dan Pimpinan/PYBMC, serta semua perubahan penting dicatat di audit log.

flowchart TD
    Start((Mulai)) --> Access["Pengguna membuka SIMPEG"]
    Access --> AuthCheck{"Sudah memiliki session SIMPEG?"}
    AuthCheck -- "Belum" --> Keycloak["Redirect login ke Keycloak SSO"]
    Keycloak --> Callback["Callback SSO ke SIMPEG"]
    Callback --> Mapping{"Email/Keycloak ID cocok dengan pegawai?"}
    Mapping -- "Tidak" --> Unregistered["Tampilkan halaman akun belum terdaftar"]
    Unregistered --> EndUnregistered((Selesai))
    Mapping -- "Ya" --> LoadRole["Load role internal dari database SIMPEG"]
    AuthCheck -- "Ya" --> LoadRole

    LoadRole --> RoleGate{"Role pengguna"}

    RoleGate -- "Admin Kepegawaian / Super Admin" --> AdminHome["Dashboard admin dan menu administrasi"]
    AdminHome --> ImportChoice{"Perlu import data awal?"}
    ImportChoice -- "Ya" --> UploadExcel["Upload daftar_pegawai.xlsx"]
    UploadExcel --> Preview["Preview 10 baris pertama dan mapping kolom"]
    Preview --> Validate["Validasi NIP, email, tanggal lahir, status, golongan"]
    Validate --> ValidDecision{"Data valid?"}
    ValidDecision -- "Tidak" --> FixReport["Tampilkan error per baris untuk diperbaiki"]
    FixReport --> UploadExcel
    ValidDecision -- "Ya" --> QueueImport["Jalankan import via queue"]
    QueueImport --> SaveEmployee["Simpan pegawai dengan profil_status belum_lengkap"]
    SaveEmployee --> AuditImport["Catat audit log import"]
    ImportChoice -- "Tidak" --> ManageEmployee["CRUD dan lengkapi profil pegawai"]
    AuditImport --> ManageEmployee
    ManageEmployee --> AuditEmployee["Catat audit log perubahan data"]

    RoleGate -- "Pegawai" --> EmployeeHome["Dashboard pegawai"]
    EmployeeHome --> LeaveRequest["Ajukan cuti"]
    LeaveRequest --> CheckBalance["Validasi saldo, jenis cuti, hari kerja, dan atasan langsung"]
    CheckBalance --> SubmitLeave["Submit cuti: status menunggu atasan langsung"]

    SubmitLeave --> SupervisorAction["Atasan Langsung mengetahui / tunda"]
    RoleGate -- "Atasan Langsung" --> SupervisorAction
    SupervisorAction --> Stage2{"Lanjut stage 2 atau ditunda?"}
    Stage2 -- "Ditunda" --> NotifyEmployee1["Notifikasi ke pegawai"]
    Stage2 -- "Lanjut" --> VerifierAction["Kabag/Verifikator menyetujui / tunda"]
    VerifierAction --> Stage3{"Lanjut final atau ditunda?"}
    Stage3 -- "Ditunda" --> NotifyEmployee2["Notifikasi ke pegawai"]
    Stage3 -- "Lanjut" --> LeaderAction["Pimpinan/PYBMC keputusan final"]
    RoleGate -- "Pimpinan" --> LeaderAction
    LeaderAction --> FinalDecision{"Disetujui?"}
    FinalDecision -- "Ya" --> UpdateLeaveBalance["Kurangi saldo cuti dan set status disetujui"]
    FinalDecision -- "Tidak/Tunda" --> NotifyEmployee3["Notifikasi keputusan ke pegawai"]
    UpdateLeaveBalance --> NotifyEmployee3
    NotifyEmployee3 --> AuditLeave["Catat audit log approval cuti"]

    Scheduler["Scheduler harian EWS"] --> CheckEvents["Cek KP, KGB, pensiun, kontrak PPPK"]
    CheckEvents --> CreateAlert["Buat EWS alert aktif"]
    CreateAlert --> SendNotif["Kirim notifikasi in-app dan email"]
    SendNotif --> AuditEws["Catat log eksekusi scheduler"]

    AdminHome --> Reports["Dashboard, export Excel/PDF, audit log"]
    Reports --> End((Selesai))
    AuditEmployee --> End
    AuditLeave --> End
    AuditEws --> End
